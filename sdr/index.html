Departamentos

Crie um departamento para cada fila da loja. Os de Venda recebem quem quer comprar: diga se atendem carro, moto ou os dois. Se houver mais de um para o mesmo tipo (ex.: duas lojas de moto), a IA alterna um cliente para cada. Os de Outro assunto recebem documentação, pós-venda etc.: diga o que vai para cada um.

Atendentes

Até 20. Nos departamentos em rodízio, cada cliente vai para o próximo atendente daquele setor, na ordem desta lista. Também são usados quando o cliente diz que já fala com alguém.

Situações especiais

Para onde vai o lead

Para ser avisado quando um lead for para o AutoCerto, ligue o Grupo de notificações no passo Follow-up → Avisos automáticos.

Funil de vendas (CRM)

Quando a IA passa um cliente para o Comercial, ela também cria a oportunidade no funil da LeadVox, com o veículo, o valor e o resumo da conversa.

Etiquetas automáticas

Enquanto conversa, a IA marca o cliente com etiquetas na LeadVox: de onde ele veio, o tipo de veículo que procura, como quer pagar e a faixa de entrada. A equipe vê tudo no card e filtra os contatos, sem abrir a conversa.

Origem: só quando o cliente chega por anúncio ou pelo site. Se ele mandar mensagem direto, o vendedor marca. A IA só troca as etiquetas dela (por exemplo, de Entrada baixa para Entrada alta).

Quando o cliente para de responder

Três perguntas, na ordem em que as coisas acontecem. Embaixo, a linha do tempo mostra o que sai e para quem.

1A IA chama o cliente de novo

Contando da última mensagem do cliente. Só sai no horário da equipe: se cair com a loja fechada, sai na abertura.

no dia seguinte (≈ 23 h)

WhatsApp oficial: depois de 24 h sem resposta, a Meta só deixa mandar mensagem modelo (template). Por isso a 3ª tentativa sai no máximo 23 h depois.

2Quando o vendedor assume

A partir daqui a IA para de falar com o cliente. O ticket vai para o Comercial com o resumo da conversa.

3Lembretes para o vendedor

Se o cliente continuar sumido depois de transferido, o vendedor recebe uma nota interna no ticket (o cliente não vê). Se o ticket estiver fechado, ele é reaberto.

No WhatsApp oficial, depois de 24 h a IA só pode falar com o cliente usando um template aprovado. Escolha qual ela manda no 7º dia para quem ainda não foi passado para a equipe. Sem template, o 7º dia vira só nota para o vendedor.
